# Sentiment classification movies reviews

Se entrenó un modelo de clasificación con Support Vector Machine (SVM) y otros modelos para predecir el sentimiento (positivo o negativo) en un dataset de reseñas de películas.

El modelo logró un accuracy del 86.97% y un F1-score por clase de 0.869 (negativo) y 0.870 (positivo).

Esto indica que el modelo mantiene un rendimiento balanceado entre ambas clases, clasificando comentarios positivos y negativos con similar efectividad. 

### **Dataset:**[ Sentiment classification 50k movies reviews](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)
